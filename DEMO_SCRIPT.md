# Charu demo walkthrough

**Length:** about 60 seconds  
**Format:** captioned screen walkthrough; the prepared MP4 has captions and no voice track. Use the narration below if recording a voiceover.

## Narration

**Opening — workbench**  
“Charu is an assembly planner for turning a design brief into a proposal you can inspect. It keeps the requirements visible instead of treating them as optional suggestions.”

**Brief and locked constraints**  
“Describe the assembly, name the required parts, and lock the connections that must remain. Set the part ceiling and geometry budget before asking the model.”

**Generated proposal**  
“Charu sends the brief to NVIDIA Nemotron through Nebius Token Factory. The response includes a spatial concept, a build sequence, and design notes. In this recorded run, the three-part camera slider preserved both required connections.”

**Validation and acceptance**  
“The server checks the returned structure, required parts, connections, part limit, and geometry budget. All seven checks passed in this run. A person still reviews the result and explicitly confirms acceptance.”

**Evidence and archive**  
“Accepted plans can be reloaded from the archive. Export evidence to save the server response with a SHA-256 integrity hash.”

**Close**  
“Charu produces a concept, not a safety certification. Independently assess any design before building or using it.”
